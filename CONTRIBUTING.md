# Contribution & Submission Guide

## For Mentees

Do not commit directly to the `main` branch.

Create a branch for every assignment:

```bash
git checkout -b your-name/week-01-ml-fundamentals
```

Complete your work, commit your changes, and push:

```bash
git add .
git commit -m "Complete Week 01 ML fundamentals assignment"
git push origin your-name/week-01-ml-fundamentals
```

Then open a Pull Request on GitHub.

## Pull Request Requirements

Every submission should contain:

- Clear README
- Well-organized code
- Comments where necessary
- Results/output
- Interpretation of findings
- Limitations
- References where applicable

## Mentor Review

Mentor feedback can be provided through:

- Pull Request comments
- Review suggestions
- GitHub Issues
- Weekly feedback documents

Mentees should respond to feedback and push revisions to the same branch.

## Important

Never commit:

- Passwords
- API keys
- Access tokens
- Cloud credentials
- Private datasets
- Personal identifying information
