# Assessment Rubric

| Criterion | Weight |
|---|---:|
| Code quality and documentation | 25% |
| Model performance and optimization | 25% |
| Project presentation and communication | 25% |
| Innovation and problem-solving approach | 25% |

## Mentor Evaluation Notes

### Code Quality & Documentation
- Code organization
- Readability
- Documentation
- Reproducibility

### Model Performance & Optimization
- Appropriate metrics
- Baseline comparison
- Model selection
- Tuning/optimization

### Presentation & Communication
- Problem framing
- Clear explanation
- Visualization
- Communication of results

### Innovation & Problem Solving
- Problem-solving approach
- Feature engineering
- Creativity
- Practical applicability
