# 3MTT Data Science & Machine Learning Mentorship

Welcome to the 3MTT Data Science & Machine Learning Mentorship Repository.

This repository serves as the central learning, collaboration, assignment,
project, feedback, assessment, and documentation hub for the 8-week program.

## Program Structure

| Week | Focus |
|------|-------|
| 1 | Machine Learning Fundamentals & Algorithm Selection |
| 2 | Data Collection & Exploratory Analysis |
| 3 | Model Development & Training |
| 4 | Deep Learning Implementation |
| 5 | Advanced SQL & Data Pipeline |
| 6 | Cloud Deployment with Azure ML |
| 7 | Model Evaluation & Optimization |
| 8 | Final Presentation & Ethics Review |

## Mentee Workflow

1. Read the weekly curriculum.
2. Read the assignment and rubric.
3. Create a branch using your name and assignment.
4. Complete the task.
5. Commit your work.
6. Push your branch to GitHub.
7. Open a Pull Request.
8. Request mentor review.
9. Address mentor feedback.
10. Push revisions to the same branch.
11. Get approval.
12. Merge when approved.

## Branch Naming

Example:

`mentee-name/week-03-model-development`

## Pull Request Naming

Example:

`Week 03 - Model Development - Mentee Name`

## Assessment

The curriculum assessment criteria are:

| Assessment Area | Weight |
|---|---:|
| Code quality and documentation | 25% |
| Model performance and optimization | 25% |
| Project presentation and communication | 25% |
| Innovation and problem-solving approach | 25% |

## Repository Philosophy

The goal is not simply to complete assignments.

Mentees should progressively build:

- Technical skills
- Analytical thinking
- Software engineering habits
- Documentation skills
- Model development skills
- Communication skills
- Portfolio-ready projects
- Responsible AI awareness
